# Mbm Plumbing Manchester — Website Mockup Concept

A homepage redesign concept for **Mbm Plumbing Manchester** in Manchester, UK — a plumbing business.

## Design
- Deep navy + aqua accents
- Fully responsive, mobile-first layout
- Built as a single self-contained HTML page (no build step)

## About this repo
Part of the [Altus Web Solutions](https://altuswebsolutions.com) free-mockup outreach series — personalized homepage concepts showing local trades businesses what a premium website could look like.

Open `index.html` in a browser to view.
